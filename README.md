# 盘州市人民医院网络安全应急演练系统

> 版本：0.2.3　适用：Windows 10/11、Windows Server 2016 及以上（局域网部署）
> 架构：Node.js + Express + SQLite 单文件数据库，前端为本机静态页面，无外部 CDN、无外网依赖。

**本系统为纯演练推演平台**：所有告警、接单、处置、上报、报案动作均为模拟记录，仅写入演练台账、取证模块与审计日志，**不会下发任何真实网络配置命令**，不操作医院生产网络、服务器与数据库。

---

## 一、系统概述

系统面向医院网络安全应急演练与桌面推演，覆盖「告警发现 → 核实研判 → 启动预案 → 分角色处置 → 业务兜底 → 上级上报 → 报案取证 → 恢复验证 → 复盘评估」全流程，内置：

- **11 类参演角色**：院应急指挥部、信息科负责人/值班员、网络安全管理员、系统管理员、医务部/门诊部负责人、临床科室/收费窗口、市卫生健康局、市网信办、市网安大队、平台系统管理员；
- **8 类医疗高频安全事件场景**：勒索病毒、内网渗透、DDoS、钓鱼邮件、系统宕机、数据泄露等，每类场景内置标准处置基线（8 个节点，其中 6 个必经步骤）；
- **两种演练模式**（共用同一套剧本基线，在新建演练项目时选定，创建后不可切换）：
  | 演练模式 | 角色工作台「角色待办任务」 | 考评方式 |
  | --- | --- | --- |
  | 基础版（引导处置） | 只展示当前一步正确流程，含处置项、引导提示与需提交表单/附件，完成后自动进入下一步 | **仅对操作时限打分**：按时完成节点数 ÷ 应完成节点总数 × 100 |
  | 实战版（自主研判） | 只展示「已发现的系统故障」，不发布处置提示，参演人员在角色工作台从三项处置方案中自主选择并实际填写发现情况与处置措施 | **扣分制**：基础分 100，决策偏离剧本 −20/项、处置超时 −10/项、演练结束仍未处置 −15/项、偏离剧本的额外操作 −5/项（上限 −20） |
- **14 个功能页面**：态势总看板、演练监视大屏、角色工作台、演练导调中心、场景剧本库与编排、演练项目管理、取证与材料归档、预案知识库、公告与舆情模拟、演练时序回放、复盘评估、演练报告导出、台账与统计、系统基础管理；
- **分级权限与数据隔离**：除院应急指挥部外，各角色仅可见/可处置本角色任务；外部单位（市卫健局、市网信办、市网安大队）仅能查看医院主动上报的表单文书、上报材料、报案材料，不可见内网原始技术日志与取证明细；
- **审计留痕**：登录、接单、提交、完成、上传、备份等操作均记录账号、角色、动作、IP、时间，审计日志仅追加、不可删除。

## 三、快速开始

### 1. 环境要求

- **Node.js ≥ 22.5.0**（系统使用 Node 内置 `node:sqlite` 模块，无需安装数据库、无需编译原生模块）；
- 端口默认 **8080**，浏览器推荐 Chrome 100+（屏幕截图取证依赖 `getDisplayMedia`）；
- 建议部署在独立演练服务器/虚拟机，与 HIS、业务网、互联网物理隔离。

### 2. 安装与启动

```powershell
cd D:\cyber-drill-system
npm install        # 依赖仅 express、multer 两个
npm start
```

首次启动自动完成：创建数据库 `data\drill.db` → 导入 11 类角色、11 个账号、8 类场景、剧本节点、任务、时序、评分项等初始数据 → 监听端口并打印访问地址。

**修改端口 / 监听地址**（可选）：

```powershell
$env:DRILL_PORT="8080"        # 端口
$env:DRILL_HOST="0.0.0.0"     # 0.0.0.0 允许局域网访问；127.0.0.1 仅本机
npm start
```

**局域网访问**需以管理员身份放行防火墙端口：

```powershell
netsh advfirewall firewall add rule name="网络安全应急演练系统" dir=in action=allow protocol=TCP localport=8080
```

## 四、页面功能与截图

### 4.1 登录

左侧角色网格点选参演角色（自动填入账号），输入密码与 4 位验证码登录；连续 5 次验证码错误锁定 10 分钟。

![登录](docs/images/usage/01-login.png)

### 4.2 态势总看板

顶部展示当前演练项目、进行状态与演练计时；卡片展示任务总数/待处理/处理中/已完成/超时、告警等级分布、角色处置进度；业务影响面板显示各系统状态（正常/受影响/中断）；下方时间线可跳转时序回放。

![态势总看板](docs/images/usage/02-dashboard.png)

### 4.3 演练监视大屏

面向指挥大厅的全局监视视图，集中展示演练态势、任务进度与关键事件。

![演练监视大屏](docs/images/usage/03-screen.png)

### 4.4 角色工作台（核心）

演练执行的唯一入口（原「任务协同中心」已并入工作台）。基础版在「角色待办任务」中**只展示当前一步正确流程**：处置动作、处置内容、引导提示、需完成事项、自动填充的表单与证据附件；完成本步骤后流程归档并自动进入下一步。实战版不发布处置步骤，只展示**已发现的系统故障**，并给出 3 个混淆处置方案（1 个符合剧本 + 2 个干扰，选项顺序稳定打乱、不提示正确项），参演人员需选择方案并实际填写发现时间、发现情况、处置措施与处置结果；选择错误计入"决策偏离"扣分，超出节点时限计入"处置超时"扣分。工作台同时汇总即时评分、扣分明细与本角色关注态势。

![角色工作台](docs/images/usage/05-workbench.png)

### 4.5 场景剧本库与编排

内置 8 类医疗高频安全事件场景，含等级、版本、节点数与状态（演练模式在新建演练项目时选择，剧本库不再标注难度），并内置标准处置基线（基础版据此下发引导任务、实战版据此判定故障发现顺序、决策偏离与超时）；支持新建场景、编辑描述、复制与版本管理。

点击场景卡片「编辑剧本」以**全屏弹窗**打开可视化编排：左侧节点库、中间纵向时序画布、节点「配置」抽屉；节点含来源/目标角色、动作、时限、关联表单、附件要求、等级，以及引导提示（基础版展示的正确流程）、流程属性与分值（正确流程/混淆流程）、下一节点接收人（多选）、判定关键词与是否必经步骤；支持拖拽排序、连线生成处置时序、保存为新版本。

![场景剧本库与编排](docs/images/usage/06-scenarios.png)

### 4.6 演练项目管理

项目列表含编号、名称、场景、参演单位、起止时间、演练模式（基础版/实战版）与状态；新建项目时必须选择演练模式（两种模式共用同一剧本基线，创建后不可切换）；支持自动生成递增项目编号、切换当前项目、更新项目状态、启停演练计时。

![演练项目管理](docs/images/usage/08-projects.png)

### 4.7 预案知识库

分类浏览应急预案、处置手册、法律法规、案例库，支持关键词搜索与详情查看；平台管理员/院应急指挥部/信息科负责人可上传文档（单文件 ≤ 20 MB）与删除文档，操作写入审计日志。

![预案知识库](docs/images/usage/09-knowledge.png)

### 4.8 演练时序回放

时间轴按分钟回放告警、接单、处置、上报、恢复等关键动作，可切换演练项目复盘任意一次演练；支持播放/暂停/拖动进度、按事件类型过滤，右侧处置时序图随回放自动点亮节点，可导出处置时序图。

![演练时序回放](docs/images/usage/10-replay.png)

### 4.9 复盘评估

按项目演练模式自动考评：基础版仅对操作时限打分；实战版采用扣分制，按「决策是否偏离剧本基线、处置是否超时、演练结束是否仍未处置、是否存在偏离剧本的额外操作」逐项扣分；展示逐节点考评明细、总分、等级、计分公式与自动生成的改进建议，「重新自动考评」结果写入评分记录并留痕。

![复盘评估](docs/images/usage/11-evaluation.png)

### 4.10 演练报告导出（仅平台系统管理员）

按演练项目生成标准《网络安全应急演练报告》，共十一章（演练概况、组织与职责分工、演练准备、实施过程、任务完成情况、演练评估、存在问题、改进建议、取证与材料归档、演练结论、附件），含封面与编制/审核/批准落款；支持预览、导出 Word、导出 HTML、打印/另存 PDF，导出动作写入审计日志。

![演练报告导出](docs/images/usage/12-report.png)

### 4.11 系统基础管理（仅平台系统管理员）

分页签操作：用户与角色管理（新建账号、启用/停用、重置密码）、表单模板管理、审计日志（仅追加不可删除，可导出 CSV）、通知与备份（「立即备份」将数据库复制到 `data\backups`）。

![系统基础管理](docs/images/usage/13-admin.png)

### 4.12 语音播报

顶栏铃铛右侧提供语音开关（默认开启，本机记忆）：新站内消息到达、角色工作台新增待办任务/待处置流程时自动语音提醒；在具体流程中逐字段填写表单时，打开流程/进入字段后延时 0.5 秒自动朗读「请填写，」+ 字段说明内容（无需点击按钮）。关闭开关后字段朗读与任务提醒静默，但**未读站内消息提醒不受开关限制**。语音基于浏览器内置 `speechSynthesis`，零依赖，推荐 Chrome / Edge。

## 六、数据、备份与审计

- **数据库**：`data\drill.db`（SQLite 单文件），含账号、角色、项目、场景、剧本、任务、表单提交、取证索引、时序、评分、台账、审计日志；
- **在线备份**：平台管理员「系统基础管理 → 立即备份」，系统先执行 WAL 检查点，再完整复制到 `data\backups\drill-时间戳.db`；
- **手工备份**：停止服务后复制 `data\drill.db` 与 `uploads\` 目录；恢复时覆盖还原后重启；
- **审计**：登录、接单、提交、完成、上传、新建账号、备份等操作均记录账号、角色、动作、IP、时间，仅追加不可删除，可导出 CSV；
- **附件规则**：单文件 ≤ 20 MB、单次最多 10 个；禁止上传 exe/bat/cmd/vbs/scr/msi/com/pif/jar/ps1/sh/dll/sys/lnk 等可执行类型；存储于 `uploads\`（按年月分目录），数据库仅存索引与路径。

## 七、安全与合规要求

1. 系统为**纯演练推演平台**：所有动作均为模拟记录，不会下发真实网络配置命令，不读写 HIS/生产数据库；
2. 必须部署在**独立演练服务器/虚拟机**，与医院 HIS、业务网、互联网物理隔离；
3. 严格执行分级权限：外部单位仅能查看医院主动上报的材料，不能查看内网原始技术日志与取证明细；
4. 演练数据**不得录入真实患者隐私信息**，一律使用虚拟测试数据；
5. 审计日志仅追加、不可删除，需按等保要求留存并定期导出归档；
6. 禁止上传真实恶意程序、病毒样本。

## 附录：详细安装部署指南

### A.1 部署前准备

**硬件与网络**

| 项目 | 最低要求 | 建议 |
| --- | --- | --- |
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 20 GB 可用 | 100 GB（取证附件长期留存） |
| 网络 | 与办公网互通 | **部署在独立演练虚拟机/服务器，与 HIS、业务网、互联网物理隔离** |

**软件要求**
- **Node.js ≥ 22.5.0**（使用 Node 内置 `node:sqlite`，无需安装数据库、无需编译原生模块）。下载：https://nodejs.org/ （建议 LTS 22.x 或 24.x，安装时勾选 "Add to PATH"）
- 端口默认 **8080**；浏览器推荐 Chrome 100+（屏幕截图取证依赖 `getDisplayMedia`）

验证 Node 版本：
```powershell
node -v
# 应输出 v22.5.0 或更高
```

### A.2 安装步骤

**复制程序目录**：将 `cyber-drill-system` 目录整体复制到服务器（如 `D:\cyber-drill-system`）。

**离线部署**：若目标服务器不能上网，可在联网电脑执行 `npm install` 后，把整个目录（含 `node_modules`）拷贝过去，跳过依赖安装。

**安装依赖**（联网环境）：
```powershell
cd D:\cyber-drill-system
npm install
```
依赖仅两个：`express`（Web 服务）、`multer`（附件上传）。

**启动服务**：
```powershell
npm start
```
首次启动自动：创建数据库 `data\drill.db` → 导入角色/账号/场景/剧本/任务/时序/评分项初始数据 → 监听端口。

启动成功后控制台显示：
```
============================================================
  盘州市人民医院网络安全应急演练系统　服务已启动
============================================================
  本机访问：   http://127.0.0.1:8080
  局域网访问： http://10.20.30.41:8080
  数据库文件： D:\cyber-drill-system\data\drill.db
  上传目录：   D:\cyber-drill-system\uploads
  停止服务：   Ctrl + C
============================================================
```

**修改端口 / 监听地址**（可选）：
```powershell
$env:DRILL_PORT="8080"
$env:DRILL_HOST="0.0.0.0"     # 0.0.0.0 允许局域网；127.0.0.1 仅本机
npm start
```

**开放防火墙端口**（局域网访问必需，以管理员身份执行）：
```powershell
netsh advfirewall firewall add rule name="网络安全应急演练系统" dir=in action=allow protocol=TCP localport=8080
```

### A.3 日常运维

**启动与停止**
- 启动：`npm start`（前台运行，关闭窗口即停止）
- 停止：在该窗口按 `Ctrl + C`
- 健康检查：浏览器访问 `http://127.0.0.1:8080/api/health` 返回 `{"ok":true,...}` 即正常

**开机自启（推荐）**
- **任务计划程序**：创建任务 → 触发器「启动时」或「登录时」→ 操作「程序 node.exe / 参数 server.js / 起始于 D:\cyber-drill-system」
- **启动脚本**：新建 `start.bat`
  ```bat
  @echo off
  cd /d %~dp0
  set DRILL_PORT=8080
  set DRILL_HOST=0.0.0.0
  node server.js
  pause
  ```
  双击启动；或加入 `shell:startup` 开机常驻。

**数据备份与恢复**
- **在线备份（推荐）**：平台管理员登录 →「系统基础管理」→「立即备份」，自动复制到 `data\backups\drill-时间戳.db`
- **手工备份**：停止服务后复制 `data\drill.db` + `uploads\` 目录
- **恢复**：停止服务 → 覆盖 `data\drill.db` 和 `uploads\` → 重启

**重置演示数据**（警告：清空现有演练数据）：
```powershell
npm run reset
```

**升级程序**
1. 备份 `data` 与 `uploads`
2. 用新版本覆盖 `server.js` / `src` / `public` / `package.json`（**不要覆盖 data / uploads**）
3. `npm install`（依赖有变化时）
4. 重启服务（数据库表结构自动迁移补齐）

### A.4 常见问题排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `node:sqlite` 模块报错 | Node 版本低于 22.5.0 | 升级至 22.5+ 并重启命令行 |
| `EADDRINUSE` | 端口被占用 | 换 `DRILL_PORT` 或 `netstat -ano \| findstr :8080` 找到占用进程 |
| 本机能开、局域网打不开 | 防火墙未放行 / 监听地址 127.0.0.1 | 执行防火墙放行；确认 `DRILL_HOST=0.0.0.0`；两台机器同网段可 ping 通 |
| "无法连接服务端" | 服务未启动或已退出 | 重新 `npm start`，访问 `/api/health` 确认 |
| 登录提示密码错误 | 密码被修改 / 账号停用 | 平台管理员在「系统基础管理」重置密码 |
| 上传附件失败 | 类型被禁止或超过 20 MB | 转换格式或压缩；禁止扩展名：exe/bat/cmd/vbs/scr/msi/com/pif/jar/ps1/sh/dll/sys/lnk |
| 屏幕截图无画面 | 浏览器不支持 `getDisplayMedia` | 使用 Chrome/Edge 最新版 |
| 页面样式错乱、数据不刷新 | 浏览器缓存 | `Ctrl + F5` 强制刷新 |
