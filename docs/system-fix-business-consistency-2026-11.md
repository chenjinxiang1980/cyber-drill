## 三、前端一致性修复

- **`api.js` 同名 `getDict` 覆盖**：内容字典改为 `getContentDict`，系统字典改为 `getSystemDict`，导出同步；`collab.html` 改用内容字典并按 `chat_channels` 取值，非管理员不再触发 403 整页报错；协同页改用 `Promise.allSettled`，单个接口失败不再拖垮整页。
- **模拟证据标记**：`api.js` 的 `getEvidence` 统一归一化名称以「(模拟)」结尾的材料为 `auto=1 + simulated=true`，避免被统计为人工取证；`report.js` 统计「模拟数据」单列，明细状态显示「模拟数据（不计人工）」，报告第九节给出显著提示；`evidence.html` 材料来源列对 `simulated` 显示「模拟数据（不计人工）」。
- **评分文案**：`evaluation.html` 与 `report.js` 删除「按时完成率×100」「每项20/10/15分」等旧口径，改为后端真实算法；考评页逐节点扣分与建议中的扣分值改为读取 `Score.deductions`/`earned`。选择改文案而不是改算法，是因为算法位于 `drill_score.go`（收尾封存线），且现有扣分梯度与报告建议一致。
- **剧本保存乐观锁**：`saveScriptNodes` 增加 `expectedVersion`；`script_nodes_write.go` 先比对客户端版本，事务内 `SELECT ... FOR UPDATE` 复核版本，冲突返回 409 并提示刷新；`scenarios.html` 保存时携带当前版本。
- **节点数统计**：保存时 `scenarios.nodes` 与响应 `count` 改为全部节点数（含干扰项/终止项），与编辑器节点总数一致。
- **大屏 4K**：支持 CSS `zoom` 的浏览器按分辨率重新布局渲染（不再先 1× 栅格化再拉伸）；不支持时限制上采样倍数为 1，宁留边不发虚。
- **触屏一体机**：不再仅凭 `pointer:coarse` 硬拦截，改为小屏（<1024）或触屏且 <1280 才拦截，1920/3840 触屏一体机可正常进入。
- **离线/陈旧提示**：连续两次刷新失败后 `LIVE` 变红色「离线」，顶栏下方出现红色提示「最后成功更新于 HH:mm:ss，当前数据可能已过期」；恢复后自动消失。

## 四、与现有剧本的冲突与处理

- **S05 原本是设备/链路故障叙事**，与 D-01「需要报公安（勒索通常已达立案标准）」不一致。处理：保留「核心存储中断」场景，但在场景说明、S05-2 核实要点和 S05-12 报案节点中明确「勒索加密/人为破坏」特征，使必报口径成立；S05-16 回执仍不作为结束前置。
- **S08 同为Ⅳ级但裁决只点名 S04**。按等级一致性套用 D-02：S08 不强制报案、保留评估后决定，结束不依赖回执。
- **基础版模拟证据写入点在 `missing_handlers.go`**（取证/备份线，本轮禁改）。处理：不改写入端，在 `api.js` 统一读取出口归一化并标注，保证报告/证据列表不再把模拟材料算作人工提交；后续取证线可把写入端同步改为 `auto=1` 并去掉前端兼容。
- **D-07 与剧本快照指纹**属于封存线实现范围，本轮未新增字段或重复实现，迁移与前端只保留与之兼容的读取方式。

### 5.1 0039 升级续报的幂等写法

- 选**方案二「不包含该句才追加」**，未选固定终值：`descr` 基线会随现场修订与其他批次迁移变化，固定终值会覆盖现场已调整的研判表述；只补缺失口径更安全。
- 实现为 `LOCATE('按升级流程重新研判', COALESCE(descr,'')) = 0`，并用 `CASE` 处理空文本，避免 `CONCAT(NULL, ...)` 与 `LIKE` 通配符歧义；重复执行不会重复追加。
- 隔离库验证（本机临时 MySQL 26.10，独立数据目录与端口 33306，不触碰现网库）：建最小 `script_nodes`/`form_templates` 表后连续执行 0039 两次，`S02-3/S06-3/S08-3` 的 `descr` 长度与 `SHA2(descr,256)` 完全一致（71/69/69），第二次执行后文本不再变化。
