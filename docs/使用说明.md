# 盘州市人民医院网络安全应急演练系统 · 使用说明

> 本系统用于**应急演练与桌面推演**。所有告警、接单、处置、上报、报案动作均为模拟记录，仅写入演练台账、取证模块与审计日志，**不会下发任何真实网络配置命令**，不操作医院生产网络、服务器与数据库。

---

## 1. 登录与入口

1. 浏览器打开 `http://服务器IP:8080`（本机为 `http://127.0.0.1:8080`）。
2. 在左侧角色网格点选本次参演角色（自动填入该角色账号），输入密码与 4 位验证码，点击「登 录」。
3. 登录后按角色权限展示不同菜单与工作台；无权限的页面会被拦截并显示“越权访问拦截”。
4. 连续 5 次验证码错误会锁定登录 10 分钟；账号密码错误不计入该锁定。

**修改密码**：登录后点击顶栏「修改密码」进入「修改登录密码」页面，输入当前密码、新密码（至少 8 位且同时包含字母与数字）并确认，提交成功后系统自动退出，请使用新密码重新登录。首次部署请立即修改初始密码 `Pzy@2026`。

> 忘记密码：由平台系统管理员登录「系统基础管理 → 用户账号」，点该账号的「重置密码」恢复为初始密码 `Pzy@2026`（重置后该账号所有登录会话自动失效）。

## 3. 演练流程总览

```
告警发现 → 核实研判 → 启动预案 → 分角色处置 → 业务兜底 → 上级上报 → 报案取证 → 恢复验证 → 复盘评估
```

对应操作路径：

1. **院应急指挥部**：态势总看板掌握全局 → 任务协同中心督办超时任务 → 协同会商中心发布指令 → 复盘阶段查看回放与评估。
2. **信息科值班员**：接收告警任务 → 填写发现表单 → 上传告警截图/日志 → 提交处置 → 完成。
3. **网络安全管理员 / 系统管理员**：处置技术任务 → 取证归档 → 恢复验证。
4. **医务/临床角色**：业务影响确认、业务兜底（纸质/人工流程）任务。
5. **外部单位**：接收上报材料 → 反馈意见（公告与舆情模块）。
6. **平台管理员**：维护场景剧本、项目、账号、表单模板、备份。

## 4. 页面使用说明

### 4.1 态势总看板（dashboard.html）

- 顶部展示当前演练项目、进行状态与演练计时；
- 卡片展示任务总数/待处理/处理中/已完成/超时、告警等级分布、角色处置进度；
- 业务影响面板显示各系统当前状态（正常/受影响/中断）与影响百分比，可随处置推进更新；
- 下方时间线展示关键节点，可跳转时序回放。

### 4.2 任务协同中心（tasks.html）★核心

**筛选与查看**：按状态（全部/待处理/处理中/已完成/超时）与接收角色筛选；超时任务高亮并在首列显示警示图标。

**打开任务详情**（点击行或「详情」）：

1. **任务信息**：任务编号、标题、来源剧本节点、接收角色、等级、时限、当前状态；
2. **需提交表单**：字段已按当前场景**自动填充模拟数据**（系统 IP、故障现象、告警来源、影响范围等），
   - 「事件发现时间」为日期时间选择器（保证格式正确）；
   - 「发现方式」既可从下拉建议中选择，也可自由填写；
   - 顶部提示：“系统已自动填充模拟数据，请核对并按实际情况修改后提交”；
   - 修改后点击「提交表单」，表单即归档到取证模块并写入审计日志；
3. **附件清单**：
   - 「上传证据附件」支持一次多选（单文件 ≤ 20 MB，最多 10 个），上传后列表**立即刷新**，无需关闭重开；
   - 支持图片缩略图预览、非图片附件的下载链接；
   - 「屏幕截图」调用浏览器原生共享屏幕能力截取当前画面，自动命名为“自动取证-…”，并同时写入附件清单与取证模块；
   - 自动生成的截图/材料带 ⚙ 标记与“自动生成”说明；
4. **流转操作**：
   - 「接单」：状态变为**处理中**；
   - 「提交处置」：写入处置记录并归档取证；
   - 「完成」：状态变为**已完成**，进入复盘与评估统计；
   - 「删除」：仅**院应急指挥部、信息科负责人**可见（信息科负责人仅限本科室条线任务）；删除后该任务的附件（含服务器文件）、表单提交与关联取证记录一并清理，并写入审计日志与回放时序；**已归档项目**的任务不可删除。

> 同一任务重复打开不会重复生成自动取证材料（按名称幂等去重）。

### 4.3 角色工作台（workbench.html）

按当前角色展示：我的待办任务、我提交的表单、相关告警与通知、快捷入口。不同角色内容不同（如值班员看告警核实，系统管理员看恢复验证）。

### 4.4 协同会商中心（collab.html）

- 按演练阶段/分组查看会商消息流；
- 发布指令或反馈（选择等级 P1/P2/P3、接收角色），消息即时进入消息流；
- 群组会话支持文字与附件，外部单位仅参与对应会商组。

### 4.5 场景剧本库（scenarios.html）

- 内置 8 类医疗高频安全事件场景：勒索病毒、内网渗透、DDoS、钓鱼邮件、系统宕机、数据泄露等；
- 每个场景含等级、难度、版本、节点数、状态（已发布/草稿），并内置**标准处置基线**（每类场景 8 个节点，其中 6 个为必经步骤）；
- 基线同时用于：基础版下发引导流程、实战版判定步骤遗漏；
- 支持新建场景、编辑描述、复制与版本管理（平台管理员/指挥部）。

### 4.6 剧本可视化编排（script-editor.html）

- 左侧节点库，中间画布，右侧属性面板；
- 节点含：来源角色、目标角色、动作、时限、关联表单、附件要求、等级；每个节点还带有**引导提示（基础版下发）**、**判定关键词**与**是否必经步骤（实战版遗漏判定依据）**；
- 支持拖拽排序、连线生成处置时序、保存为新版本；保存后自动同步场景剧本库的节点数与版本号（如 v1.0 → v1.1）。

### 4.7 演练项目管理（projects.html）

- 项目列表：编号、名称、场景、参演单位、起止时间、**演练模式（基础版/实战版）**、状态（筹备/演练中/已结束）；
- 支持新建演练项目（平台管理员/指挥部/信息科负责人）：点击右上角「新建演练项目」，填写项目名称、演练类型、关联剧本、计划日期与参演单位，创建后状态为「未开始」，自动生成递增项目编号（如 P2026-013）并写入数据库，刷新后仍保留；
- 新建时未指定演练模式的项目默认按**基础版**创建，可在复盘评估页调整为实战版（已结束项目不可调整）；
- 可切换当前项目（顶栏项目名处也可切换），切换后所有页面数据按项目过滤；
- 可更新项目状态、启停演练计时。

### 4.8 取证与材料归档（evidence.html）

- 按类型归档：截图、日志片段、流量包摘要、配置备份、文档、表单文书、处置记录、上报材料、报案材料；
- 支持上传真实文件、按类型筛选、下载与预览；
- 自动取证材料标注来源任务与“自动生成”；
- **外部单位登录时仅显示表单文书/上报材料/报案材料**。

### 4.9 预案知识库（knowledge.html）

- 分类浏览应急预案、处置手册、法律法规、案例库；
- 支持关键词搜索与详情查看，供各角色处置时参考；
- **上传文档**（仅平台管理员/院应急指挥部/信息科负责人可见入口）：点击右上角「上传文档」，填写文档名称、选择分类并选择本地文件（PDF/Word/Excel/PPT/文本/图片/压缩包，单文件 ≤ 20 MB），提交后立即出现在列表并生成 KB 编号（如 KB7）；
- **删除文档**（同上权限）：点击行内「删除」并二次确认，服务器上的原文件同时清理，操作写入审计日志；内置 KB1~KB6 示例文档同样可删除；
- 自行上传的文档在「预览」中显示原件归档信息与「下载原件」按钮，下载会记录审计日志；系统内置文档预览为条目化虚拟文本；
- 禁止上传真实恶意程序、病毒样本与含真实患者隐私的材料。

### 4.10 公告与舆情模拟（opinion.html）

- 模拟对外公告发布与舆情监测（渠道、热度、风险等级、处置状态）；
- 支持新增公告、更新舆情研判状态；
- 市网信办角色可在此查看与反馈。

### 4.11 演练时序回放（replay.html）

- 时间轴按分钟回放告警、接单、处置、上报、恢复等关键动作；
- 页面右上角可**切换演练项目**，复盘任意一次演练（默认当前项目）；也可从「演练报告导出」页点「时序回放」直接跳到报告所选项目；
- 可播放/暂停/拖动进度、按事件类型过滤，查看每个节点的操作角色、耗时与证据附件；
- 右侧处置时序图随回放自动点亮节点，回放统计展示事件数、P0/P1 数量、闭环时长与超时节点数；
- 支持导出处置时序图（用于报告插图）；
- 回放数据仅按项目读取时序库，外部单位（市卫健局/市网信办/市网安大队）无回放权限；院应急指挥部、信息科负责人、网络安全管理员、系统管理员、平台系统管理员可查看。

### 4.12 复盘评估（evaluation.html）

系统按演练项目的**演练模式**采用不同考评口径，全部自动计算：

| 演练模式 | 考评方式 | 计分规则 |
| --- | --- | --- |
| 基础版（诱导演练） | 系统按剧本节点逐节点下发任务，并在工作台给出处置引导提示，参演人员按提示完成 | **仅对操作时限打分**：按时完成节点数 ÷ 应完成节点总数 × 100（以接单→完成耗时对照节点时限） |
| 实战版（自主处置） | 系统不提供固定流程，参演人员在工作台/复盘页自行添加处置步骤（动作类型 + 标题 + 实际时刻） | **步骤遗漏 70% + 时限 30%**：完整性 = 已覆盖基线必经步骤 ÷ 基线必经步骤；时限达成 = 已覆盖步骤中在基线时限内的比例 |

- 实战版步骤录入后，系统按「动作类型 + 关键词 + 责任角色」自动匹配基础版基线节点，未匹配的步骤标记为「额外处置」；
- 复盘页展示逐节点考评明细（按时 / 超时 / 遗漏）、总分、等级、计分公式与自动生成的改进建议；
- 指挥部、信息科负责人、平台管理员可在复盘页切换当前项目的演练模式（已结束项目不可切换）；
- 点击「重新自动考评」将结果写入评分记录并留痕，作为「演练报告导出」评分章节的数据来源。

### 4.13 演练报告导出（report.html，仅平台系统管理员）

- 位于左侧「复盘与报送」栏目，按演练项目生成标准《网络安全应急演练报告》；
- 页面右上角「时序回放」可跳转到**当前报告所选项目**的事件回放页，便于导出前核对处置过程；
- 报告共十一章：演练概况、组织与职责分工、演练准备、实施过程、任务完成情况、演练评估、存在问题、改进建议、取证与材料归档、演练结论、附件；含封面（密级/编号）与编制、审核、批准落款；
- 可勾选是否附「处置时序表」「任务明细表」「取证材料清单」「审计留痕摘要」；
- 支持四种输出方式：「预览报告」（页面内查看）、「导出 Word」（.doc）、「导出 HTML」、「打印 / 另存 PDF」；
- 导出动作写入审计日志；报告数据全部取自演练数据库，不含真实患者隐私信息。

### 4.14 台账与统计（ledger.html）

- 记录每次演练的项目、场景、参演单位、起止时间、任务完成率、平均响应时长、评分；
- 支持按时间/场景筛选与导出统计表，用于年度演练台账归档。

### 4.15 系统基础管理（admin.html，仅平台系统管理员）

可分页签操作：

| 页签 | 功能 |
| --- | --- |
| 用户与角色管理 | 查看真实账号列表、新建账号（初始密码 `Pzy@2026`）、启用/停用、重置密码（重置后该账号会话失效） |
| 表单模板管理 | 查看/新建表单模板（模板名称 + 字段清单） |
| 审计日志 | 查看全部操作记录（时间、账号、角色、动作、IP），仅追加不可删除，可导出 CSV |
| 通知与备份 | 配置演练通知渠道；「立即备份」将数据库复制到 `data\backups`，显示文件名、大小与上次备份时间 |

## 5. 关键操作指引

### 5.1 完成一条值班员任务（示例）

1. 用户名 `liming` 登录 → 进入「任务协同中心」；
2. 点击待处理任务「详情」；
3. 核对表单中自动填充的模拟数据（IP、故障现象、发现方式等），按实际修改；
4. 点「上传证据附件」选择告警截图/日志，或用「屏幕截图」现场取证；
5. 点「提交表单」→ 再点「接单」→「提交处置」→「完成」；
6. 状态依次变为 处理中 → 已完成，取证模块同步出现对应材料。

### 5.2 指挥部督办超时任务

1. `yuanzhang` 登录 → 任务协同中心；
2. 筛选「超时」，点击行内「督办」；
3. 系统向该任务接收角色推送督办消息（模拟），记录写入台账；
4. 顶部「人工触发督办消息」可批量提醒所有超时任务。

### 5.3 信息科负责人统筹条线任务

1. `chendongzhu` 登录；
2. 任务协同中心仅显示值班员、网络安全管理员、系统管理员、信息科负责人的任务；
3. 可直接接单/提交/完成这些任务；
4. 领导小组、上级主管、市网信办、市网安大队任务不显示、不可操作。

### 5.4 外部单位查看上报材料

1. `zhoukeyuan`（市卫健局）登录 → 「取证与材料归档」；
2. 仅可见「表单文书/上报材料/报案材料」三类；
3. 点击可预览或下载，内网日志类材料不出现。

### 5.5 导出演练报告

1. 平台系统管理员 `admin` 登录 → 左侧「复盘与报送 → 演练报告导出」；
2. 选择演练项目（默认当前演练项目）；
3. 按需勾选处置时序表、任务明细表、取证材料清单、审计留痕摘要；
4. 点击「预览报告」核对内容，或直接「导出 Word」「导出 HTML」「打印 / 另存 PDF」；
5. 导出文件命名：`网络安全应急演练报告-项目编号-日期.doc`，导出动作自动记入审计日志；
6. 报告「六、演练评估」章节会引用复盘页「重新自动考评」生成的模式化评分（基础版时限达成率 / 实战版遗漏 70% + 时限 30%）。

### 5.6 实战版自主处置步骤录入

1. 使用任一参演角色登录（如 `yuanzhang`）→「角色工作台」；
2. 当前项目为**实战版**时，工作台显示「实战版处置步骤录入」卡片；先选择**动作类型**（告警核实 / 隔离处置 / 处置恢复 / 业务兜底 / 上报审批 / 取证留痕 / 协同沟通 / 其他）；
3. 填写**步骤标题**（如“隔离感染主机并关闭共享写入”）、选择**处置时刻**，可补充说明（主机 IP、操作对象等）；
4. 点击「添加处置步骤」：系统按「动作类型 + 判定关键词 + 责任角色」自动匹配基础版基线节点，并提示匹配到的节点编号与是否在时限内；未匹配的步骤记为“额外处置”；
5. 按实际处置过程重复录入全部步骤；录入有误的步骤可由本人或院应急指挥部/平台管理员删除；
6. 进入「复盘评估」查看遗漏步骤、时限达成与综合得分（遗漏 70% + 时限 30%），点击「重新自动考评」写入评分记录；
7. 基础版项目不支持自主添加步骤（接口会拒绝），请改用完整诱导演练流程。

## 6. 附件与取证规则

| 规则 | 说明 |
| --- | --- |
| 允许类型 | 图片（png/jpg/jpeg/gif/webp）、文本与日志（txt/log/csv/json）、文档（doc/docx/xls/xlsx/pdf）、压缩包（zip/rar/7z）、流量包（pcap/pcapng）等 |
| 禁止类型 | exe、bat、cmd、vbs、scr、msi、com、pif、jar、ps1、sh、dll、sys、lnk |
| 大小限制 | 单文件 ≤ 20 MB，单次最多 10 个 |
| 存储位置 | `uploads\` 目录（按年月分目录），数据库仅存索引与路径 |
| 自动取证 | 系统按场景自动生成告警截图与故障截图，归档至取证模块，按名称幂等去重 |
| 不可篡改 | 审计日志仅追加，无删除接口；附件删除操作本身也会记入审计 |

## 7. 数据与审计

- **数据库**：`data\drill.db`（SQLite 单文件），含账号、角色、项目、场景、剧本、任务、表单提交、取证索引、时序、评分、台账、审计日志。
- **备份**：平台管理员「系统基础管理 → 立即备份」，生成 `data\backups\drill-时间戳.db`；恢复方式见《安装说明》3.3。
- **审计**：登录、接单、提交、完成、上传、新建账号、备份等操作均记录账号、角色、动作、IP、时间，可在「系统基础管理 → 审计日志」查看与导出 CSV。

## 8. 使用注意事项

1. 演练数据请使用**虚拟测试数据**，禁止录入真实患者姓名、身份证号、病历号等隐私信息。
2. 所有操作按钮均带“演练模拟”提示，仅产生记录，不代表真实处置；正式应急请按医院实际预案执行。
3. 系统自动填充的 IP、故障现象、告警来源为**示例数据**，提交前请按本次演练设定核对修改。
4. 不要多人使用同一账号同时操作，避免任务状态互相覆盖；按参演角色分配账号。
5. 建议演练前由平台管理员确认：场景已发布、项目状态为“演练中”、参演账号均可登录、磁盘剩余空间充足。
6. 演练结束后：导出演练报告与审计日志 → 在线备份 → 归档 `uploads` 取证材料。
