# 盘州市人民医院网络安全应急演练系统 · 使用说明

> 本系统用于**应急演练与桌面推演**。所有告警、接单、处置、上报、报案动作均为模拟记录，仅写入演练台账、取证模块与审计日志，**不会下发任何真实网络配置命令**，不操作医院生产网络、服务器与数据库。

---

## 1. 登录与入口

1. 浏览器打开 `http://服务器IP:8080`（本机为 `http://127.0.0.1:8080`）。
2. 在左侧角色网格点选本次参演角色（自动填入该角色账号），输入密码与 4 位验证码，点击「登 录」。
3. 登录后按角色权限展示不同菜单与工作台；无权限的页面会被拦截并显示“越权访问拦截”。
4. 连续 5 次验证码错误会锁定登录 10 分钟；账号密码错误不计入该锁定。

**修改密码**：登录后点击顶栏「修改密码」进入「修改登录密码」页面，输入当前密码、新密码（至少 8 位且同时包含字母与数字）并确认，提交成功后系统自动退出，请使用新密码重新登录。首次部署请立即修改初始密码 `Pzy@2026`。

> 忘记密码：由平台系统管理员登录「系统基础管理 → 用户账号」，点该账号的「重置密码」恢复为初始密码 `Pzy@2026`（重置后该账号所有登录会话自动失效）。

## 3. 演练流程总览

```
告警发现 → 核实研判 → 启动预案 → 分角色处置 → 业务兜底 → 上级上报 → 报案取证 → 恢复验证 → 复盘评估
```

对应操作路径：

1. **院应急指挥部**：态势总看板掌握全局 → 演练导调中心发布指令 → 复盘阶段查看回放与评估。
2. **信息科值班员**：接收告警任务 → 填写发现表单 → 上传告警截图/日志 → 提交处置 → 完成。
3. **网络安全管理员 / 系统管理员**：处置技术任务 → 取证归档 → 恢复验证。
4. **医务/临床角色**：业务影响确认、业务兜底（纸质/人工流程）任务。
5. **外部单位**：接收上报材料 → 反馈意见（公告与舆情模块）。
6. **平台管理员**：维护场景剧本、项目、账号、表单模板、备份。

## 4. 页面使用说明

### 4.1 态势总看板（dashboard.html）

- 顶部展示当前演练项目、进行状态与**真实演练计时（T+HH:MM:SS，按启动时刻每秒计时）**；
- 卡片展示任务总数/待处理/处理中/已完成/超时、告警等级分布、角色处置进度；
- 业务影响面板显示各系统当前状态（正常/受影响/中断）与影响百分比，可随处置推进更新；
- 下方时间线展示关键节点，可跳转时序回放。

### 4.2 角色工作台（workbench.html）★核心

演练执行的唯一入口（原「任务协同中心」已并入工作台），按当前角色展示岗位职责、角色待办任务、即时评分与本角色关注态势。

**基础版：按依赖并行开放正确流程**

1. 「角色待办任务」按剧本依赖展示本角色流程：**前置流程已全部完成**的流程标记为「可处置（并行）」，可同时点开多个流程处置；前置未完成的流程置灰标记「前置未完成」并列出待完成事项，不可打开表单；
2. 「需完成事项」列出本流程应做的三件事；完成后点击「完成本流程」，系统归档本流程（接单 → 提交处置 → 完成），其后续流程在满足前置条件时自动开放（可能同时开放多个）；
3. **需提交表单**：字段已按当前场景**自动填充模拟数据**（系统 IP、故障现象、告警来源、影响范围等），「事件发现时间」为日期时间选择器，「发现方式」可从下拉建议中选择或自由填写；核对修改后点击「提交表单」，表单归档到取证模块并写入审计日志；
4. **证据附件**：
   - 「上传 / 截图」支持一次多选（单文件 ≤ 20 MB，最多 10 个），上传后列表**立即刷新**；
   - 支持图片缩略图点击放大预览、非图片附件的下载链接；
   - 「屏幕截图」调用浏览器原生共享屏幕能力截取当前画面，自动命名并同时写入附件清单与取证模块；
   - 工作台会按当前场景自动生成告警截图与系统故障截图作为模拟取证材料（带 ⚙ 标记，按任务+名称幂等去重）。

**实战版：候选处置流程（正确流程 + 混淆流程）+ 自主流转**

1. 进入工作台自动弹出「演练系统异常 · 已发现故障警告」，展示故障现象、发现时刻、已发现故障数、涉及系统、影响范围与关联线索；
2. 「角色待办任务」不发布处置步骤与引导提示，只列出本角色可处置的**全部候选流程**——外观与排序完全一致，系统不标记正确/混淆、不显示分值，参演人员需自行研判（赋能较好的角色可能只有 2 个正确流程，实战版会额外混合 3 个混淆流程）；
3. 点击列表行弹窗打开处置表单：表单字段为空表手填（无任何自动预填），并需勾选**下一节点接收人**（按角色列出，可多选；所选接收人与剧本预设集合完全一致才正确，多选、漏选均扣本流程 10% 分值）、填写发现情况（可选）、实际处置措施、处置结果与证据说明；
4. 若判定某个流程不属于本岗应执行的处置动作，可点击该行右侧「**跳过（不执行）**」并确认：流程标记为「已跳过（未执行）」且锁定，无需填写表单。原须知中混合的混淆流程即可用该方式排除——**跳过混淆流程奖励 +2 分**（总分封顶 100）；若跳过的是正确流程，结束演练时按该流程分值扣分；
5. 提交后即时判定并提示：正确流程按设置分值得分（超时完成按 90% 计），混淆流程按该流程分值直接扣分；提交后该流程锁定不可修改；
6. 评分卡实时汇总正确流程完成数 / 待处置 / 已跳过 / 混淆流程误选 / 超时 / 接收人错误以及扣分、奖励明细；
7. **完成演练**：仅院应急指挥部、平台管理员、信息科负责人可点。点击前系统校验「取证与材料归档」——本场景仍有未归档的取证材料时按钮置灰不可点（显示「完成演练（取证 x/y）」），接口亦返回 400 拦截；取齐后结束演练，未完成的正确流程按该流程分值扣分，总分限定 0–100。

> 不同角色显示不同待办（如值班员看告警核实，系统管理员看恢复验证）；指挥部/平台管理员在实战版可督导全部环节。

### 4.3 演练导调中心（collab.html）

- 提供两个真实聊天频道：**院内演练会商**（院内参演角色同步研判结论、处置进展与资源需求）与**院外上报沟通**（向市卫健局、市网信办、市网安大队报送材料与进展、接收反馈）；
- 消息与附件写入演练数据库，其他参演角色登录后即可看到历史消息，页面每 4 秒自动同步新消息，也可点「刷新消息」立即拉取；每条消息时间按 `YYYY-MM-DD HH:mm` 完整格式显示（如 2026-10-24 10:03）；
- 支持文字与**真实文件附件**：单文件 ≤ 20 MB，禁止 exe/bat/jar 等可执行与脚本类文件；图片附件可点击查看原图，其他附件可下载；聊天附件同步归档至「取证与材料归档」；
- 所有发言记入审计日志，包含账号、角色、频道、内容摘要与时间，可用于复盘留痕；
- **频道权限**：
  | 角色 | 院内演练会商 | 院外上报沟通 |
  | --- | --- | --- |
  | 信息科值班员、网络安全管理员、系统管理员、医务部/门诊部负责人、临床科室/收费窗口 | ✔ 可用 | — 不可见 |
  | 市卫生健康局、市网信办、市网安大队 | — 不可见 | ✔ 可用 |
  | 信息科负责人、院应急指挥部 | ✔ 可用 | ✔ 可用 |

  页面只显示当前角色有权限的频道，越权访问接口将返回 403；院外单位看不到任何院内会商内容。

- **演练节点操作情况**：聊天区左侧面板实时展示当前演练项目的节点处置进展，仅显示「处置中」与「已完成」的节点，待处置节点不展示；参演人员在角色工作台**打开处置表单即视为处置中**（基础版点击待办任务、实战版点击故障处置均会记录），提交后转为已完成（实战版决策偏离标记为「决策偏离」）；院内角色在院内频道可同时看到院内处置与院外上报沟通阶段的节点，院外单位在院外频道仅能看到院外上报沟通阶段的节点。

### 4.4 场景剧本库与剧本编排（scenarios.html）

- 内置 8 类医疗高频安全事件场景：勒索病毒、内网渗透、DDoS、钓鱼邮件、系统宕机、数据泄露等；
- 每个场景含等级、版本、节点数、状态（已发布/草稿），并内置**标准处置基线**（每类场景 8 个节点，其中 6 个为必经步骤）；演练模式（基础版/实战版）在新建演练项目时选择，剧本库不再标注难度；
- 基线同时用于：基础版按节点下发引导任务、实战版按节点顺序放出故障并判定决策偏离、超时与未处置；
- 支持新建场景、编辑描述、复制与版本管理（平台管理员/指挥部）；
- 点击场景卡片「编辑剧本」以**全屏弹窗**打开**并行可视化编排画布**，无需跳转独立页面；左侧为节点类型库，中间为**依赖图画布**（节点卡片 + 依赖连线），下方为**混淆流程池**，点击节点「配置」打开属性抽屉；
- **并行依赖图**：每个节点可配置任意多个**前置节点**（也可在画布上从节点右侧圆点按住拖拽连线到目标节点建立依赖，点击连线可删除）；只有全部前置流程完成后，本流程才会开放，因此同一阶段可存在多个并行推进的流程；混淆流程不参与依赖流转，单独放在下方混淆流程池；
- **剧本名称**：编排弹窗顶部可直接编辑剧本名称（必填，最长 60 字），随「保存剧本」一并提交，保存后场景剧本库卡片、下拉选项与弹窗标题同步更新；
- **自动布局**：按依赖深度分列、按责任角色分泳道自动排列节点；也可直接拖动节点卡片调整位置，坐标随剧本保存；
- **循环依赖校验**：连线或保存时会检查依赖是否成环，若成环将拒绝保存并提示检查前置关系；
- 节点含：来源角色、目标角色、动作、时限、关联表单、附件要求、等级；每个节点还带有**流程属性（正确流程 / 混淆流程）**、**本步骤分值**、**下一节点接收人**、**前置节点**、**引导提示（基础版展示的正确流程）**、**判定关键词**与**是否必经步骤**；
- **流程属性与分值**：正确流程完成按本步骤分值计分（超时完成按 90% 计，接收人选错再扣 10%），所有正确流程分值合计满分 100，超过 100 分时属性面板与保存前均给出红色超分提醒；混淆流程仅实战版显示，被选中时按该分值直接扣分、不计入满分；基础版不显示混淆流程；
- **下一节点接收人**：设置本流程完成后的流转角色，**支持多选**（勾选多个角色）；留空保存时按依赖关系取**后继流程**的责任角色自动补齐（多个后继时取并集，无后继时流转至院应急指挥部）。基础版在处置表单中展示剧本预设接收人并自动流转；实战版需参演人员自行勾选，所选接收人与预设集合完全一致才正确，多选、漏选均扣本流程 10% 分值；
- **需取证材料**：在节点属性「需取证材料」中按行填写 `类型|材料名称|取证说明`（最多 6 项，类型可选附件截图 / 操作日志 / 处置记录 / 样本摘要 / 表单文书 / 上报材料 / 报案材料 / 附件）；可点击「按剧本自动生成」依据节点标题、动作、引导提示与关联表单生成相符的模拟取证材料清单；留空保存时系统也会按剧本自动生成，供演练中逐项提醒取证；
- 「预览推演」按依赖层次播放：同一层的并行节点同时高亮，逐层推进；
- 保存时按依赖关系重新计算节点时序并保存为新版本，自动同步场景剧本库的节点数与版本号（如 v1.0 → v1.1）；存量剧本升级后会按原顺序自动建立串行依赖（行为与升级前一致），后续可在画布上改为并行。

### 4.5 演练项目管理（projects.html）

- 项目列表：编号、名称、场景、参演单位、起止时间、**演练模式（基础版/实战版）**、状态（筹备/演练中/已结束）；
- 支持新建演练项目（平台管理员/指挥部/信息科负责人）：点击右上角「新建演练项目」，填写项目名称、演练类型、关联剧本、计划日期与参演单位，勾选**参演角色**并**必须选择演练模式**（两种模式共用同一套剧本基线，创建后不可切换），创建后状态为「未开始」，自动生成递增项目编号（如 P2026-013）并写入数据库，刷新后仍保留；
- **参演编组按角色维护**：新建时勾选参演角色，也可在项目列表点「编组」继续追加（仅可选尚未加入的角色，自动去重并落库）；编组不指定具体人员，凡使用该角色演练账号登录即视为该角色参演；
- 基础版项目创建时系统按剧本节点自动下发任务并匹配表单；实战版项目不生成任务，工作台只展示后续“已发现”的故障；
- 可切换当前项目（顶栏项目名处也可切换），切换后所有页面数据按项目过滤；
- 可更新项目状态；**演练计时按真实时间计算**：启动时记录开始时刻（顶栏与工作台显示 T+HH:MM:SS），暂停时冻结、继续时扣除暂停时长，结束后冻结定格，恢复演练不重置起点；

### 4.6 取证与材料归档（evidence.html）

- 按类型归档：附件截图、操作日志、处置记录、样本摘要、表单文书、上报材料、报案材料、附件；
- **本场景需取证材料（剧本要求，逐项提醒）**：页面顶部按当前项目剧本逐项列出各节点需要归档的材料，显示所属节点、责任角色、材料类型/名称与取证说明，以及「已归档 / 待取证」状态；统计按「本角色 已归档 x / 本角色总数」与「全场景 x / 总数」两个口径展示，本角色有未归档材料时会弹出提醒；
  - **按角色划分取证责任**：每项材料只能由该剧本节点标注的责任角色取证——网络安全管理员负责网络隔离、样本与日志固定等节点；系统管理员负责备份检查、业务恢复验证等节点；信息科值班员负责接报与范围核实；信息科负责人可统筹本科室条线（值班员/网安/系统管理员）材料；院应急指挥部与平台管理员可统筹全部。其他角色节点的材料显示为「由 XXX 负责」，不提供取证按钮，也不能通过接口代填（返回 403）；
  - 每项可直接点击「**模拟材料**」一键导入与剧本相符的取证材料：截图类生成 SVG 模拟取证界面（含场景名、告警内容、节点、责任角色、计划时刻与处置状态），操作日志类生成含节点处置动作与执行结果的日志片段，处置记录/样本摘要等生成 .md/.txt 文本材料；同一项重复导入自动去重；导入后请核对并按实际处置修改；
  - 也可点击「上传真实材料」「屏幕截图」针对该项取证，归档后该状态即时变为「已归档」，可查看或下载；
- **真实材料取证**：
  - 「上传真实材料」可选择本地文件（截图、日志片段、文书等，单文件 ≤ 20 MB，可多选），支持选择类型、归档场景与取证说明，禁止 exe/bat/cmd/ps1/vbs/js/jar 等可执行与脚本类文件；
  - 「屏幕截图取证」调用浏览器原生共享屏幕能力，截取当前画面后直接作为真实图片文件归档，自动命名可修改；
- **按剧本预填材料（按角色范围）**：仅列出当前角色负责节点中尚未归档的取证材料，按节点分组，可修改名称与取证说明、取消勾选；确认后系统按剧本生成相符的模拟文件（截图 SVG / 日志文本）并归档，其他角色负责的材料会被跳过，不能由一个角色一次性填充全部材料；
- **跨场景归档查询**：列表包含全部演练项目归档的材料，可通过「全部场景 / 指定场景」下拉切换查看其他场景的材料，并显示所属场景、来源（真实文件上传 / 系统自动采集 / 预填记录）、归档时间与上传人；
- 支持按类型筛选、详情查看、图片预览与真实文件下载（下载记入审计日志）；归档后不可删除；
- 自动取证材料标注来源任务与“自动生成”；
- **外部单位登录时仅显示表单文书/上报材料/报案材料**，且不可上传、截图、预填或打包。

### 4.7 预案知识库（knowledge.html）

- 分类浏览应急预案、处置手册、法律法规、案例库；
- 支持关键词搜索与详情查看，供各角色处置时参考；
- **上传文档**（仅平台管理员/院应急指挥部/信息科负责人可见入口）：点击右上角「上传文档」，填写文档名称、选择分类并选择本地文件（PDF/Word/Excel/PPT/文本/图片/压缩包，单文件 ≤ 20 MB），提交后立即出现在列表并生成 KB 编号（如 KB7）；
- **删除文档**（同上权限）：点击行内「删除」并二次确认，服务器上的原文件同时清理，操作写入审计日志；内置 KB1~KB6 示例文档同样可删除；
- 自行上传的文档在「预览」中显示原件归档信息与「下载原件」按钮，下载会记录审计日志；系统内置文档预览为条目化虚拟文本；
- 禁止上传真实恶意程序、病毒样本与含真实患者隐私的材料。

### 4.8 公告与舆情模拟（opinion.html）

- 模拟对外公告发布与舆情监测（渠道、热度、风险等级、处置状态）；
- 支持新增公告、更新舆情研判状态；
- 市网信办角色可在此查看与反馈。

### 4.9 演练时序回放（replay.html）

- 时间轴按分钟回放告警、接单、处置、上报、恢复等关键动作；
- 页面右上角可**切换演练项目**，复盘任意一次演练（默认当前项目）；也可从「演练报告导出」页点「时序回放」直接跳到报告所选项目；
- 可播放/暂停/拖动进度、按事件类型过滤，查看每个节点的操作角色、耗时与证据附件；
- 右侧处置时序图随回放自动点亮节点，回放统计展示事件数、P0/P1 数量、闭环时长与超时节点数；
- 支持导出处置时序图（用于报告插图）；
- 回放数据仅按项目读取时序库，外部单位（市卫健局/市网信办/市网安大队）无回放权限；院应急指挥部、信息科负责人、网络安全管理员、系统管理员、平台系统管理员可查看。

### 4.10 复盘评估（evaluation.html）

系统按演练项目的**演练模式**采用不同考评口径，全部自动计算：

| 演练模式 | 考评方式 | 计分规则 |
| --- | --- | --- |
| 基础版（引导处置） | 项目创建后系统按剧本节点自动在角色工作台「角色待办任务」中展示正确流程：**前置流程已全部完成的流程并行开放**（可同时处置），前置未完成的流程置灰锁定，含处置动作、处置内容、引导提示，并自动填充相关表单与告警截图 | **仅对操作时限打分**：按时完成节点数 ÷ 应完成节点总数 × 100（以接单→完成耗时对照节点时限） |
| 实战版（自主研判） | 系统**不发布处置步骤与工作提示**，只在角色工作台展示“已发现的系统故障”；参演人员对每个已发现故障从混淆方案中自主选择，并实际填写发现时间、发现情况、处置措施与结果 | **扣分制**：基础分 100；与剧本基线偏离 −20/项，处置超时 −10/项，演练结束仍未处置 −15/项，偏离剧本的额外操作 −5/项（上限 −20） |

- 实战版故障按剧本依赖**渐进放开**：前置流程完成（提交或跳过）后，后续流程才解锁；未解锁流程在列表中置灰并标记「前置未完成」，不可提交、不可跳过；混淆流程不参与依赖，始终可选；
- 实战版每个环节提供 3 个处置选项（1 个符合预案 + 2 个干扰项，如“外网防火墙受攻击是否需要上报领导小组启动预案”“是否直接停诊”等），选项位置按节点稳定打乱，提交前系统不提示正确项；
- 每个环节需填写：发现时间（datetime-local）、发现情况（≥6 字）、处置措施（≥6 字）、处置结果、证据材料说明（可选，自动写入取证模块）；
- 已提交环节即时锁定不可修改，同一环节不可重复提交；系统按剧本基线逐环节判定「按时 / 超时 / 决策有误 / 待处置 / 遗漏」；
- 复盘页展示逐节点考评明细、总分、等级、计分公式与自动生成的改进建议；实战版另以只读表格展示各环节的选择方案、判定、处置时刻与发现情况/措施/结果；
- 演练模式在新建演练项目时选定，创建后不可切换；
- 点击「重新自动考评」将结果写入评分记录并留痕，作为「演练报告导出」评分章节的数据来源。

### 4.11 演练报告导出（report.html，仅平台系统管理员）

- 位于左侧「复盘与报送」栏目，按演练项目生成标准《网络安全应急演练报告》；
- 页面右上角「时序回放」可跳转到**当前报告所选项目**的事件回放页，便于导出前核对处置过程；
- 报告共十一章：演练概况、组织与职责分工、演练准备、实施过程、任务完成情况、演练评估、存在问题、改进建议、取证与材料归档、演练结论、附件；含封面（密级/编号）与编制、审核、批准落款；
- 可勾选是否附「处置时序表」「任务明细表」「取证材料清单」「审计留痕摘要」；
- 支持四种输出方式：「预览报告」（页面内查看）、「导出 Word」（.doc）、「导出 HTML」、「打印 / 另存 PDF」；
- 导出动作写入审计日志；报告数据全部取自演练数据库，不含真实患者隐私信息。

### 4.12 台账与统计（ledger.html）

### 4.13 系统基础管理（admin.html，仅平台系统管理员）

可分页签操作：

| 页签 | 功能 |
| --- | --- |

### 4.14 语音播报（顶栏喇叭）

- 顶栏铃铛右侧为**语音开关**（喇叭图标，默认开启，状态记忆在本机浏览器）；关闭后字段朗读、任务提醒等全部静默；
- **消息提醒**：站内消息轮询发现新的未读消息时，自动语音播报消息标题与摘要；进入系统时如存在未读消息，也会提醒未读数量；**消息提醒不受语音开关限制**，即使关闭喇叭仍会提醒；
- **任务提醒**：角色工作台待办任务（基础版）或待处置流程（实战版）新增时，语音播报新增数量，请及时处理；完成推进不播报；
- **字段自动朗读**：在具体流程中处理任务、逐字段填写表单时，打开流程/进入字段后延时 0.5 秒自动朗读「请填写，」+ 该字段的说明内容，无需点击任何按钮；仅播报字段说明本身，不播报字段名称、序号等其他内容；关闭语音开关后停止朗读；
- 语音基于浏览器内置语音合成能力（零依赖），推荐使用 Chrome / Edge；若浏览器不支持，喇叭按钮会提示不支持。

## 5. 关键操作指引

### 5.1 基础版按流程完成一步（示例）

1. 用户名 `liming`（信息科值班员）登录 → 进入「角色工作台」；
2. 「角色待办任务」只显示当前一步正确流程，核对处置动作、处置内容与引导提示；
3. 核对表单中自动填充的模拟数据（IP、故障现象、发现方式等），按实际修改；标准化字段（发现方式、事件类型、事件等级、响应等级、风险等级）为下拉选择，日期时间字段使用标准化日期时间选择器填写（统一 `YYYY-MM-DD HH:mm` 格式）；

5. 点「提交表单」，再点「完成本步骤，进入下一流程」；
6. 本步骤自动归档（接单 → 提交处置 → 完成），工作台立即切换到下一步；全部完成后显示“本角色负责的流程已全部完成”。

### 5.2 指挥部掌握全局与督办

1. `yuanzhang` 登录 → 「态势总看板」查看各角色任务进度、超时与告警分布；
2. 「演练导调中心」发布指令，向相关角色推送督办消息（演练模拟）；
3. 复盘阶段在「演练时序回放」查看处置过程，在「复盘评估」查看时限达成与扣分明细。

### 5.3 信息科负责人统筹本科室条线

1. `chendongzhu` 登录 → 「角色工作台」执行本人负责的剧本节点；
2. 本科室值班员、网络安全管理员、系统管理员按各自账号登录后，在工作台完成各自步骤；
3. 复盘阶段可查看本条线各环节的完成情况与超时统计；
4. 领导小组、上级主管、市网信办、市网安大队的任务不显示、不可操作。

### 5.4 外部单位查看上报材料

1. `zhoukeyuan`（市卫健局）登录 → 「取证与材料归档」；
2. 仅可见「表单文书/上报材料/报案材料」三类；
3. 点击可预览或下载，内网日志类材料不出现。

### 5.5 导出演练报告

1. 平台系统管理员 `admin` 登录 → 左侧「复盘与报送 → 演练报告导出」；
2. 选择演练项目（默认当前演练项目）；
3. 按需勾选处置时序表、任务明细表、取证材料清单、审计留痕摘要；
4. 点击「预览报告」核对内容，或直接「导出 Word」「导出 HTML」「打印 / 另存 PDF」；
5. 导出文件命名：`网络安全应急演练报告-项目编号-日期.doc`，导出动作自动记入审计日志；
6. 报告「六、演练评估」章节会引用复盘页「重新自动考评」生成的模式化评分（基础版时限达成率 / 实战版扣分制得分与扣分明细）；实战版报告的「五、演练任务完成情况」章节改为展示基线环节处置覆盖率、决策正确/有误统计与逐条处置决策记录。

### 5.6 实战版自主研判处置

1. 由院应急指挥部/信息科负责人/平台管理员在「演练项目管理」新建项目时选择**实战版**（两种模式共用同一套剧本基线，创建后不可切换），并将项目状态更新为「演练中」；
2. 使用任一参演角色登录（如 `liming`）→「角色工作台」；
3. 当前项目为**实战版**时，系统自动弹出「演练系统异常 · 已发现故障警告」，展示故障现象、发现时刻、涉及系统、影响范围与关联线索，并可点「查看异常告警」重新查看；
4. 工作台不显示任务提示，而显示「实战处置决策」卡片：按角色列出本角色可处置的**已发现故障**（指挥部/平台管理员可督导全部环节）；
5. 展开任一环节，从 3 个处置选项中**自主选择**方案（系统不提示正确项），再填写**发现时间**、**发现情况**（≥6 字）、**处置措施**（≥6 字）、**处置结果**与证据材料说明；
6. 点击「提交处置记录」：系统立即按剧本基线判定该环节决策是否正确、是否时限内，并反馈当前得分与扣分明细，同时自动写入取证模块与回放时序；提交后该环节锁定不可修改，系统随即放出下一个故障；
7. 逐环节完成本角色处置后，进入「复盘评估」查看逐环节判定、决策正确性、时限达成与扣分明细，点击「重新自动考评」写入评分记录；
8. 工作台「角色待办任务」在实战版下只展示**已发现的系统故障**（发现时刻、现象、影响范围、处置状态），不发布处置步骤与引导提示，避免提前泄露处置流程；
9. 评分规则：基础分 100，决策偏离剧本 −20/项、处置超时 −10/项、演练结束仍未处置 −15/项、偏离剧本的额外操作 −5/项（上限 −20）。

## 6. 附件与取证规则

| 规则 | 说明 |
| --- | --- |
| 允许类型 | 图片（png/jpg/jpeg/gif/webp）、文本与日志（txt/log/csv/json）、文档（doc/docx/xls/xlsx/pdf）、压缩包（zip/rar/7z）、流量包（pcap/pcapng）等 |
| 禁止类型 | exe、bat、cmd、vbs、scr、msi、com、pif、jar、ps1、sh、dll、sys、lnk |
| 大小限制 | 单文件 ≤ 20 MB，单次最多 10 个 |
| 存储位置 | `uploads\` 目录（按年月分目录），数据库仅存索引与路径 |
| 自动取证 | 系统按场景自动生成告警截图与故障截图，归档至取证模块，按名称幂等去重 |
| 不可篡改 | 审计日志仅追加，无删除接口；附件删除操作本身也会记入审计 |

## 7. 数据与审计

- **数据库**：`data\drill.db`（SQLite 单文件），含账号、角色、项目、场景、剧本、任务、表单提交、取证索引、时序、评分、台账、审计日志。
- **备份**：平台管理员「系统基础管理 → 立即备份」，生成 `data\backups\drill-时间戳.db`；恢复方式见《安装说明》3.3。
- **审计**：登录、接单、提交、完成、上传、新建账号、备份等操作均记录账号、角色、动作、IP、时间，可在「系统基础管理 → 审计日志」查看与导出 CSV。

---

## 8. 使用注意事项

1. 演练数据请使用**虚拟测试数据**，禁止录入真实患者姓名、身份证号、病历号等隐私信息。
2. 所有操作按钮均带“演练模拟”提示，仅产生记录，不代表真实处置；正式应急请按医院实际预案执行。
3. 系统自动填充的 IP、故障现象、告警来源为**示例数据**，提交前请按本次演练设定核对修改。
4. 不要多人使用同一账号同时操作，避免任务状态互相覆盖；按参演角色分配账号。
5. 建议演练前由平台管理员确认：场景已发布、项目状态为“演练中”、参演账号均可登录、磁盘剩余空间充足。
6. 演练结束后：导出演练报告与审计日志 → 在线备份 → 归档 `uploads` 取证材料。
